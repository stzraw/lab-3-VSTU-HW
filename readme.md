Написать и отладить программу вычисления силы тяжести при

## 1. Алгоритм и блок-схема

### **Алгоритм**
1. **Начало**
2. Подключить необходимые библиотеки и задать константы:
   - `<locale.h>` - для работы с локалью (поддержка русского языка).
   - `<stdio.h>` - для ввода и вывода данных (puts, scanf, printf).

4. Определить функцию `main()` - точку входа в программу:
   - Объявить переменные типа double: `h` (высота падения), `m` (масса тела), `pw` (сила тяжести).
   - Установить русскую локаль: `setlocale(LC_CTYPE, "RUS")`.
5. Запросить у пользователя и считать с клавиатуры исходные данные:
   - Ввести высоту падения `h` в метрах.

6. Вызвать функцию расчёта `calc_gravity(h, m)`, передав ей аргументы `h` и `m`.

   - Вычислить силу тяжести: `force = m * g`.
   - Вернуть вычисленное значение `force` в вызывающую функцию `main()`.
8. В функции `main()` сохранить возвращённое значение в переменную `pw`.
9. Вывести на экран значение силы тяжести с форматированием до двух знаков после запятой (`printf`) и завершить функцию `main()`, вернув 0.
10. **Конец**

## 2. Реализация программы

#define _CRT_SECURE_NO_DEPRECATE
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>

#define R 6371000.0
#define GM 3.986004418e14

double calc_gravity(double h, double m);

int main()
{
    double h, m;
    double pw;

    setlocale(LC_CTYPE, "RUS");

    puts("Введите высоту падения (м):");
    scanf("%lf", &h);

    puts("Введите массу тела (кг):");
    scanf("%lf", &m);
    pw = calc_gravity(h, m);

    printf("Сила тяжести равна: %.2f Н\n", pw);
    return 0;
}

double calc_gravity(double h, double m)
{
    double g;
    double force;

    g = GM / ((R + h) * (R + h));
    force = m * g;
    return force;
}

Если ввести, например, h=100м и m=10кг, вывод будет: **Сила тяжести равна: 98.20 Н**
